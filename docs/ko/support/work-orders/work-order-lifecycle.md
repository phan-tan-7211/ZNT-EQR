**대상:** 매니저, 관리자, 소유자, 기술자  
**최종 검토일:** 2026-07-04
모든 작업 지시는 동일한 수명 주기를 거칩니다. 상세 페이지에는 유효한 다음 상태 버튼만 표시되므로 아래의 권한 규칙은 UI와 데이터베이스 양쪽에서 적용됩니다.

## 1. 상태 흐름

- **제출됨** — 생성되었으나 아직 검토되지 않았습니다.
- **접수됨** — 검토를 거쳐 일정 지정이 승인되었습니다.
- **배정됨** — 특정 기술자나 팀에 전달되었습니다.
- **진행 중** — 작업이 시작되었습니다.
- **보류 중** — 일시 중지되었습니다(부품, 고객 또는 출입 대기).
- **완료됨** — 작업이 끝나고 기록되었습니다.
- **취소됨** — 작업이 더 이상 필요하지 않을 때의 최종 상태입니다.

## 2. 누가 무엇을 변경할 수 있나요

| 전환 | 허용된 역할 |
| --- | --- |
| 제출됨 → 접수됨 | 매니저, 관리자, 소유자 |
| 접수됨 → 배정됨 | 매니저, 관리자, 소유자 |
| 배정됨 → 진행 중 | 매니저 이상 또는 배정된 기술자 |
| 진행 중 → 완료됨 | 매니저 이상 또는 배정된 기술자 |
| 모든 상태 → 보류 중 | 매니저 이상 또는 배정된 기술자 |
| 모든 상태 → 취소됨 | 매니저, 관리자, 소유자 |

## 3. 취소됨과 완료됨의 차이

완료됨은 종료일을 자동으로 기록하며, 이 날짜가 보고서와 기한 초과 계산에 사용됩니다. 취소됨은 작업 지시를 이력에 남기되 완료된 작업으로 집계하지 않는 최종 상태입니다.

## 4. 작업 지시 상세의 설비 위치

작업 지시가 설비에 연결되어 있으면 상세 페이지에 설비 기록에서 사용하는 것과 같은 위치 출처 드롭다운과 미니 지도가 포함됩니다. 배차 담당자는 기술자를 보내기 전에 적용 위치, 팀 위치, 설비 위치, 최근 스캔 위치 출처를 미리 볼 수 있습니다.
