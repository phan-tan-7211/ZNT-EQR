**대상:** 기술자, 매니저, 소유자, 관리자  
**최종 검토일:** 2026-07-04

::: info 필요 조건
작업 지시가 아직 진행 중이어야 합니다. **완료됨** 또는 **취소됨** 상태가 아니어야 합니다.
:::

기술자와 매니저는 작업 지시를 삭제하고 사진이나 메모를 다시 기록할 필요 없이 잘못 지정된 예방정비(PM) 템플릿을 바로잡을 수 있습니다. PM 체크리스트를 변경하거나 제거해도 작업 지시의 사진, 메모, 비용, 상태 이력은 그대로 유지됩니다.

## 1. 작업 지시 열기

**작업 지시**에서 업데이트할 진행 중인 작업을 엽니다.

## 2. PM 관리 시작

작업 지시 상세 페이지에서 다음 중 하나를 선택합니다.

- 작업 지시가 PM 없이 생성된 경우 **예방 정비 점검 목록 추가**
- PM 체크리스트가 이미 첨부된 경우 **예방 정비 템플릿 관리**

![PM 체크리스트 관리 대화 상자](https://wgynakhoppqkrutnslmv.supabase.co/storage/v1/object/public/docs-media/support/work-order-pm/desktop/01-add-pm-dialog.png)

## 3. PM 체크리스트 추가

1. **예방 정비 템플릿** 드롭다운에서 알맞은 템플릿을 선택합니다. 설비에 기본 템플릿이 있지만 이 작업에 다른 템플릿이 필요하다면 여기에서 바꿀 수 있습니다.
2. **예방 정비 변경 사항 저장**을 선택합니다.

ZNTEQR이 PM 체크리스트를 생성하고 작업 지시를 PM 사용 상태로 설정합니다.

![템플릿을 첨부한 후의 PM 체크리스트 섹션](https://wgynakhoppqkrutnslmv.supabase.co/storage/v1/object/public/docs-media/support/work-order-pm/desktop/02-pm-checklist-after-add.png)

## 4. 예방정비 템플릿 변경

1. **예방 정비 템플릿 관리**를 엽니다.
2. 다른 체크리스트 템플릿을 선택합니다.
3. **예방 정비 변경 사항 저장**을 선택합니다.

현재 체크리스트에 완료된 항목이나 PM 메모가 이미 있으면 ZNTEQR이 PM 데이터를 초기화하기 전에 경고를 표시합니다. PM 체크리스트만 교체되며 작업 지시의 사진과 메모는 그대로 남습니다.

::: tip 템플릿을 변경하기 전에
완료한 점검 항목의 기록이 필요하다면 작업 지시에서 PM 체크리스트 PDF를 다운로드해 두세요.
:::

## 5. PM 체크리스트 제거

1. **예방 정비 템플릿 관리**를 엽니다.
2. **예방 정비 템플릿**을 **없음**으로 설정합니다(또는 드롭다운 옆의 지우기 컨트롤을 사용합니다).
3. **예방 정비 변경 사항 저장**을 선택합니다.

작업 지시에서 PM 섹션이 사라집니다. 메모, 사진, 비용은 작업 지시에 그대로 남습니다.

## 예방정비 템플릿을 관리할 수 있는 사람

| 역할 | 진행 중인 작업 지시에서 PM 추가 / 변경 / 제거 |
| --- | --- |
| 소유자 / 관리자 | 예 |
| 매니저 / 기술자(팀 구성원) | 예 |
| 요청자 / 조회자 | 아니요 |
