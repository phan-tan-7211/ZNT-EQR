# 작업 지시

여러 팀에 걸쳐 작업 지시를 생성, 배정, 예약하고 종료합니다.

## 문서

- [작업 지시 수명 주기 참조](./work-order-lifecycle) — 전체 상태 흐름과, 각 상태 간에 작업 지시를 변경할 수 있는 사람을 설명합니다.
- [진행 중인 작업 지시에서 예방정비 템플릿 관리하기](./manage-pm-template-on-work-order) — 작업 지시가 완료되거나 취소되기 전에 PM 체크리스트를 추가, 변경 또는 제거합니다.
- [제출된 작업 요청 분류하기](./triage-submitted-requests) — 매니저가 요청자의 제출 건을 처리하는 방법: 검토, 접수 또는 거절, 일정 지정, 배정.
- [작업 지시 배정하기](./assign-work-order) — 작업 지시를 개인, 팀 또는 둘 다에 배정하고, 배정이 알림과 대시보드에 어떤 영향을 주는지 알아봅니다.
- [보고서 페이지 읽기](./reports-overview) — 보고서 페이지를 열어 여러 팀의 처리량, 대기 작업, 기한 초과 작업을 확인합니다.
- [요청자로 작업 요청 제출하기](./submit-request-as-requestor) — 설비 소유자나 신뢰할 수 있는 고객이 설비의 QR 코드를 스캔해 담당 팀에 바로 작업 요청을 보낼 수 있습니다.
