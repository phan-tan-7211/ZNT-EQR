**대상:** 매니저, 관리자, 소유자  
**최종 검토일:** 2026-05-01
요청자가 제출한 건은 **제출됨** 상태로 팀의 작업 대기열에 들어옵니다. 매니저는 다음 단계를 결정합니다. 접수하고 일정을 잡아 배정하거나, 사유를 적고 취소합니다.

## 1. 작업 지시 열기

사이드바 또는 모바일 하단 내비게이션에서 작업 지시 페이지를 엽니다. 제출됨 상태로 필터링해 대기열을 확인합니다.

## 2. 각 요청 검토

요청을 열어 요청자의 설명, 사진, 해당 설비를 확인합니다. 작업이 실제로 우리 팀 소관인지 확인합니다.

## 3. 접수 또는 취소

**접수**를 클릭해 작업 지시를 접수됨 상태로 진행합니다. 처리할 수 없는 요청이라면 **취소**를 사용하고, 요청자가 상황을 알 수 있도록 짧은 사유를 추가합니다.

## 4. 우선순위와 마감일 설정

우선순위와 마감일에 따라 기술자의 일일 대기열과 대시보드의 기한 초과 지표가 정해집니다.

## 5. 기술자 또는 팀 배정

담당자 드롭다운에서 개인을 선택하거나, 팀을 선택하거나, 둘 다 선택합니다. 상태 업데이트에서는 개인 배정이 우선합니다.
