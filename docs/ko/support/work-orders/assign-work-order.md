**대상:** 매니저, 관리자, 소유자  
**최종 검토일:** 2026-05-01
## 1. 작업 지시 열기

작업 지시 목록이나 설비 페이지에서 배정하려는 작업의 상세 화면을 엽니다.

## 2. 담당자 선택

"담당자" 컨트롤을 열고 기술자를 선택합니다. 개인에게 배정하면 해당 담당자의 내 작업 지시 보기에 작업 지시가 표시됩니다.

## 3. 팀 선택(선택 사항)

필요하면 팀을 배정해 모든 팀원이 작업 지시를 볼 수 있게 합니다. 둘 다 설정한 경우 개인 담당자가 상태 업데이트의 주 책임자가 됩니다.

## 4. 상태 진행

개인이 맡게 되면 작업 지시를 배정됨으로 설정합니다. 팀이 함께 처리하는 작업이라면 접수됨으로 두어도 괜찮지만, 배정됨으로 설정하면 대시보드에서 더 명확하게 보입니다.
