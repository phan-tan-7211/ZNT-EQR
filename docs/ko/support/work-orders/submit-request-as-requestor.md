**대상:** 요청자  
**최종 검토일:** 2026-05-01

::: info 필요 조건
해당 설비의 팀에 요청자로 추가되어 있어야 합니다.
:::

요청자 역할은 설비를 소유하거나 책임지는 사람을 위해 만들어졌습니다. 정비소에 전화하는 대신 QR 코드를 스캔해 1분 안에 요청을 제출할 수 있습니다.

## 1. 설비 QR 코드 스캔

휴대폰 카메라로 설비에 붙은 QR 스티커를 비추고 배너를 눌러 ZNTEQR을 엽니다.

## 2. 요청 제출 누르기

읽기 전용 기록 대신, 스캔한 설비가 미리 입력된 요청 제출 양식이 표시됩니다.

## 3. 문제 설명하기

제목, 우선순위, 설명은 필수입니다. 문제를 설명하는 데 도움이 된다면 사진을 추가하세요.

## 4. 제출

요청이 제출됨 상태로 팀 대기열에 표시됩니다. "내 작업 지시"에서 요청을 확인할 수 있으며, 매니저가 배정하고 완료하는 과정의 업데이트를 볼 수 있습니다.

::: tip 참고
요청자는 작업 지시를 제출한 후에는 수정할 수 없습니다. 정보를 추가해야 하면 팀의 매니저에게 문의하세요.
:::
