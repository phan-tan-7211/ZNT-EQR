# 개인정보 및 지원

문제를 신고하고, 문의 내역을 확인하고, 개인정보 요청을 제출하고, 감사 로그를 사용합니다.

## 문서

- [개인정보 요청 제출하기](./submit-privacy-request) — 로그인한 계정이 없어도 내 데이터의 열람, 정정, 삭제 또는 판매·공유 거부를 요청할 수 있습니다.
- [감사 로그 사용하기](./audit-log-basics) — 관리자와 소유자는 누가 언제 무엇을 했는지 확인할 수 있습니다. 조사와 규정 준수 증빙에 유용합니다.
- [개인정보 담당자를 위한 DSR 관리 화면](./dsr-cockpit-overview) — 관리자와 소유자가 정보주체 요청을 확인, 연장, 완료 또는 거부 단계를 거쳐 처리하는 곳입니다.
- [시스템 상태 확인하기](./system-status) — ZNTEQR에는 공개 상태 페이지가 없습니다. 무언가 고장 난 것처럼 보일 때 해야 할 일을 안내합니다.
- [버그 또는 문제 신고하기](./report-an-issue) — 대시보드에서 바로 문의를 제출하세요. 세션 진단 정보가 자동으로 첨부되며 개인정보는 필요하지 않습니다.
- [신고한 문제 추적하기](./track-my-tickets) — 대시보드 지원 페이지의 내가 신고한 문제에서 문의 상태와 팀의 답변을 확인합니다.
