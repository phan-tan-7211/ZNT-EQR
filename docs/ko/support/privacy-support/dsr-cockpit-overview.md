**대상:** 관리자, 소유자  
**최종 검토일:** 2026-07-19

::: info 필요 권한
DSR 관리 화면은 조직 소유자와 관리자만 사용할 수 있습니다.
:::

## 1. DSR 관리 화면 열기

바닥글에서 **법적 고지**를 열고 **DSR 관리 화면**을 선택하거나, **설정 → 개인정보**로 이동하여 **정보주체 요청 관리**를 클릭합니다. 대기열에는 조치가 필요한 모든 미처리 요청이 표시됩니다.

## 2. 케이스 열기

행을 클릭하여 해당 케이스를 엽니다. 타임라인에는 모든 상태 변경, 증빙 내보내기 시도, 발송된 소비자 통지가 표시됩니다.

## 3. 다음 조치 수행

- **확인** — 요청자가 해당 데이터의 주인인지 확인합니다.
- **연장** — 법정 최대 기한까지 처리 기한을 연장합니다.
- **거부** — 사유를 기록하고 종료합니다.
- **완료** — 데이터를 제공, 정정 또는 삭제한 후 처리 완료로 표시합니다.
- **내보내기 요청 / 내보내기 재시도** — 증빙 패키지를 생성합니다.
- **알림 재전송** — 소비자 통지를 다시 발송합니다.

## 4. 관리자가 아닌 사용자에게는 404 또는 403이 표시됩니다

구성원에게는 DSR 관리 화면 경로가 절대 표시되지 않습니다. 다른 조직에 대한 요청은 404를 반환하여, 다른 조직이 요청을 받았다는 사실조차 노출되지 않도록 합니다.
