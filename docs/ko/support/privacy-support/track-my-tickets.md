::: tip ZNTEQR 앱에서
이 작업은 로그인 후 이용하는 지원 페이지에서 진행됩니다: [https://eqr.zinitek.com/dashboard/support](https://eqr.zinitek.com/dashboard/support).
:::

## 1. 지원 페이지 열기

사용자 메뉴(오른쪽 상단)에서 **지원 및 문의**를 열거나 `/dashboard/support`로 이동합니다.

## 2. 문의 펼치기

문의는 지원 페이지의 도움받기 아래에 표시됩니다. 문의를 클릭하면 펼쳐져 설명, 세션 진단 정보, 팀의 답변을 볼 수 있습니다.

## 3. 실시간 업데이트 확인

ZNTEQR 팀이 댓글을 달거나 문의를 종료하면 해당 행이 실시간으로 업데이트됩니다. 상태 배지(열림 / 처리 중 / 종료됨)는 GitHub의 상태를 그대로 반영합니다.
