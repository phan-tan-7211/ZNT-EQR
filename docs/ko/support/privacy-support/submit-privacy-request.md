**대상:** 모든 사용자  
**최종 검토일:** 2026-05-01
개인정보 요청은 `/privacy-request`의 전용 접수 창구를 통해 처리됩니다. 누구나 제출할 수 있으며 로그인할 필요가 없습니다.

## 1. 개인정보 요청 양식 열기

https://eqr.zinitek.com/privacy-request 로 이동하거나(바닥글의 '판매 또는 공유 거부'에 링크되어 있습니다) 앱 안에서 /privacy-request를 엽니다.

## 2. 내 정보 입력

- **성명** — 고객님의 기록을 식별하는 데 사용합니다.
- **이메일 주소** — 답변을 보내 드릴 주소입니다.
- **요청 유형** — 내 정보 열람, 내 정보 정정, 내 정보 삭제, 내 개인정보 판매 또는 공유 거부, 민감한 개인정보 사용 제한 중에서 선택합니다.
- **추가 내용** — 요청을 더 빨리 처리하는 데 도움이 되는 선택 정보입니다.

## 3. hCaptcha 완료

캡차가 표시되면 제출하기 전에 완료하세요. 접수 엔드포인트가 자동화된 방식으로 악용되는 것을 막아 줍니다.

## 4. 제출하고 답변 기다리기

제출하면 성공 확인 메시지가 표시됩니다. ZNTEQR 개인정보 담당자가 요청을 검토하고 접수 사실을 알려 드린 다음, 법정 기한(일반적으로 45일, 최대 90일까지 연장 가능) 내에 처리합니다.
