**대상:** 모든 사용자  
**최종 검토일:** 2026-10-11

ZNTEQR은 별도의 시스템 상태 페이지를 운영하지 않습니다. 앱이 고장 난 것처럼 보이거나 로드되지 않으면 지원 페이지를 이용하세요.

## 1. 내 쪽 문제가 아닌지 확인

페이지를 새로 고치고 기기가 온라인 상태인지 확인합니다. 현장에서 휴대폰으로 ZNTEQR을 사용한다면, 서비스가 중단되었다고 판단하기 전에 신호가 잡히는지 확인하세요.

## 2. 지원 페이지 열기

아무 브라우저에서나 [eqr.zinitek.com/support](https://eqr.zinitek.com/support)로 이동합니다. 로그인할 필요가 없습니다. **도움받기** 카드에 지원 이메일 주소와 예상 응답 시간이 나와 있습니다.

## 3. 로그인할 수 있으면 앱에서 문제 신고

아직 로그인할 수 있다면 [eqr.zinitek.com/dashboard/support](https://eqr.zinitek.com/dashboard/support)에서 로그인 후 이용하는 지원 페이지를 열고 **문제 신고**를 클릭합니다. 세션 진단 정보가 자동으로 첨부되며, **내가 신고한 문제**에서 문의 진행 상황을 확인할 수 있습니다.
