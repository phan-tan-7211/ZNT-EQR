**대상:** 관리자, 소유자  
**최종 검토일:** 2026-07-06

::: info 필요 권한
조직 소유자 또는 관리자여야 합니다. 감사 로그에는 민감하고 높은 권한이 필요한 정보가 들어 있으며, 다른 어떤 역할에게도 표시되지 않습니다. 앱에서도, 데이터베이스 수준에서도 마찬가지입니다.
:::

## 1. 조직 설정에서 감사 로그 열기

**조직 → 감사 로그**로 이동합니다. 감사 로그는 의도적으로 기본 탐색 메뉴가 아닌 조직 설정 안에 배치되어 있습니다. 감사 로그를 볼 때는 정확히 한 조직의 전체 변경 기록을 보게 됩니다.

이전 사이드바 위치로 저장해 둔 북마크는 자동으로 리디렉션됩니다.

## 2. 보기 필터링

대상 유형, 작업, 수행자 또는 기간으로 필터링하고, 타임라인 히스토그램을 사용하여 특정 활동 구간을 확대합니다. 필터를 사용하면 특정 사건으로 범위를 좁히거나 규정 준수 증빙을 만들 수 있습니다.

상세 페이지(작업 지시, 재고 품목)는 해당 기록으로 미리 필터링된 감사 로그로 바로 연결되므로, 감사 데이터가 운영 타임라인과 섞이는 일이 없습니다.

## 3. 이벤트를 열어 상세 정보 보기

아무 행이나 클릭하면 누가 수행했는지, 무엇이 변경되었는지, 관련 기록은 무엇인지를 포함한 전체 이벤트 내용을 볼 수 있습니다.

## 4. 감사 증빙 내보내기

다운로드 메뉴를 사용하여 필터링된 보기를 CSV 또는 JSON으로 내보냅니다. 감사 로그 내보내기는 전용 경로로 처리되며, 감사 항목은 작업 지시, 보고서 또는 기타 데이터 내보내기에 절대 포함되지 않습니다. 내보내기를 할 때마다 조직의 관리자에게 알림이 전송됩니다.

::: tip 참고
감사 이벤트는 한번 기록되면 변경할 수 없습니다. 항목을 삭제하거나 편집할 수 없으며, 바로 그 점 때문에 로그가 증빙으로서 가치를 가집니다.
:::
