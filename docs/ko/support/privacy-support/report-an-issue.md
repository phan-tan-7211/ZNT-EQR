**대상:** 모든 사용자  
**최종 검토일:** 2026-05-01

::: tip ZNTEQR 앱에서
이 작업은 로그인 후 이용하는 지원 페이지에서 진행됩니다: [https://eqr.zinitek.com/dashboard/support](https://eqr.zinitek.com/dashboard/support).
:::

이 페이지의 문제 신고 버튼을 누르면 ZNTEQR 팀이 즉시 확인할 수 있는 문의가 생성됩니다. 익명 처리된 세션 진단 정보가 자동으로 첨부되므로, 로그를 붙여 넣지 않으셔도 대부분의 문제를 저희가 재현할 수 있습니다.

## 1. 문제 신고 클릭

이 버튼은 지원 페이지 상단의 도움받기 카드에 있습니다. 로그인한 모든 사용자가 사용할 수 있습니다.

## 2. 명확한 제목과 재현 단계 작성

- **제목** — 저희 문의 목록에 표시되는 짧은 요약입니다.
- **설명** — 기대했던 결과, 실제로 일어난 일, 재현 방법을 적어 주세요.

## 3. 제출

문의가 즉시 등록됩니다. 확인 알림이 표시되고 대화 상자가 닫힙니다.

## 4. 내가 신고한 문제에서 진행 상황 확인

내가 신고한 문제에는 상태(열림 / 처리 중 / 종료됨)와 팀의 답변이 표시됩니다. 업데이트는 Supabase Realtime을 통해 실시간으로 반영되므로 새로 고칠 필요가 없습니다.


세션 진단 정보에는 앱 버전, 브라우저, 현재 경로, 조직 ID/요금제, 오류 키가 포함됩니다. 하지만 이름, 이메일, 팀 소속 정보, 세션 토큰은 절대 포함되지 않습니다.
