**대상:** 관리자, 소유자  
**최종 검토일:** 2026-07-06

::: info 필요 권한
조직 소유자 또는 관리자.
:::

ZNTEQR의 온보딩은 두 단계로 이루어집니다. 먼저 사용자가 **조직**에 가입하고, 그다음 여러분이 사용자를 **팀**에 추가합니다. 구성원은 팀에 소속되기 전까지 설비를 볼 수 없습니다.

## 1. 조직 → 구성원 열기

사이드바에서 **조직**으로 이동한 다음 **구성원** 탭을 선택합니다.


## 2. 구성원 초대 클릭

초대할 사람의 업무용 이메일 주소를 입력합니다. 주소를 다시 한번 확인하세요. 초대는 7일간 유효하며, 개인 메일함으로 보내면 반송되는 경우가 많습니다.

## 3. 조직 역할 선택

- **관리자** — 조직 전체의 구성원, 팀, 설비, 연동을 관리합니다.
- **구성원** — 가입한 팀으로부터 접근 권한을 물려받는 직원 계정입니다. 구성원은 팀에 추가되기 전까지 어떤 설비도 볼 수 없습니다.

## 4. 사용자를 팀에 추가

**팀**으로 이동하여 이 사용자가 작업할 설비를 담당하는 팀을 열고 **구성원 추가**를 클릭합니다. 담당 업무에 맞는 팀 역할(매니저, 기술자, 요청자 또는 조회자)을 선택합니다.


## 5. 팀원에게 진행 과정 알려 주기

초대 이메일은 다음과 같이 발송됩니다.

- **보낸 사람:** ZNTEQR <noreply@zinitek.com>
- **제목:** "You're invited to join [Your Organization] on ZNTEQR"
- **링크 만료:** 발송 후 7일.

::: tip 참고
초대 메일이 5~10분 안에 도착하지 않으면, 다시 보내기 전에 스팸함을 확인해 달라고 요청하세요.
:::
