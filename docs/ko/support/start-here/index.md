- [ZNTEQR에 오신 것을 환영합니다](./welcome-to-znteqr) — ZNTEQR이 하는 일과 각 팀 역할이 주로 사용하는 화면을 60초 만에 살펴봅니다.
- [앱 화면 구성 익히기](./navigation-tour) — 사이드바, 상단 바, 모바일 하단 탐색 메뉴, 그리고 관리자 전용 화면의 위치를 빠르게 둘러봅니다.
- [팀원 초대하기](./invite-team-members) — 새 사용자가 로그인할 수 있도록 조직 초대를 보낸 다음, 그들이 정비하는 설비를 담당하는 팀에 추가합니다.
- [ZNTEQR 역할 개요](./role-overview) — 두 가지 역할 계층(조직과 팀)과 각 역할이 할 수 있는 일을 쉬운 말로 정리한 요약표입니다.
