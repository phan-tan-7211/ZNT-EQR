**대상:** 관리자, 소유자  
**최종 검토일:** 2026-05-02

::: info 필요 조건
조직 소유자 또는 관리자여야 합니다.
:::

## 1. 설비 → 설비 일괄 수정 열기

설비 목록에서 일괄 수정 버튼을 사용합니다(또는 /dashboard/equipment/bulk로 직접 이동합니다).

## 2. 수정할 행 선택

행의 체크박스를 사용하여 변경할 설비 기록을 선택합니다. 먼저 검색하고 정렬하여 목록을 좁힐 수 있습니다.

## 3. 그리드에서 셀 수정

셀을 클릭하여 이름, 상태, 위치, 팀 지정 등의 필드를 변경합니다. 수정 내용은 저장하기 전까지 로컬에만 유지됩니다.

## 4. 변경 사항 저장

저장(Commit, 또는 일괄 수정 도구 모음의 해당 작업)을 사용하여 수정한 모든 행을 저장합니다. 데이터가 기록되기 전에 유효성 검사가 실행됩니다.

::: tip 참고
완전히 새로운 설비는 목록의 설비 추가에서 추가합니다. 일괄 수정은 기존 행을 수정하는 용도입니다.
:::
