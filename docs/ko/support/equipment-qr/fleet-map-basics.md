**최종 검토일:** 2026-07-04

설비 지도에는 위치가 있는 모든 설비가 표시됩니다. 배차할 때와 특정 현장에 어떤 설비가 있는지 확인할 때 가장 유용합니다.

## 1. 설비 지도 열기

사이드바에서 설비 지도를 선택합니다. 좌표가 확인된 모든 설비 핀과 함께 지도가 표시됩니다.

## 2. 위치 출처별로 필터링

**위치 출처** 범례와 드롭다운을 사용하여 적용 위치, 팀 본부, 설비 주소 또는 최근 스캔 GPS별로 마커를 필터링합니다. 이는 설비 상세 페이지의 출처 드롭다운과 동일합니다.

![설비 지도 위치 출처 필터](https://wgynakhoppqkrutnslmv.supabase.co/storage/v1/object/public/docs-media/support/location-maps/desktop/01-fleet-map-source-filter.png)

ZNTEQR이 적용 핀을 선택하는 방식은 [설비 위치 출처와 지도](./location-sources-and-maps)를 참조하세요.

## 3. 확대하여 클러스터 보기

가까이 있는 설비는 그룹 핀으로 묶입니다. 클러스터를 클릭하면 확대되며, 개별 핀이 설비 이름 및 상태와 함께 펼쳐집니다.

## 4. 핀을 클릭하여 기록 열기

핀 팝업에는 설비 이름, 상태, 상세 페이지 바로가기가 표시됩니다. 이를 사용해 작업 지시를 시작하거나 정비 이력을 확인하세요.

## 5. 설비 기록에서 누락된 위치 업데이트

지도에 설비가 표시되지 않으면 해당 기록을 열고 위치 지도 카드에서 지정 주소를 설정하거나 실시간 GPS를 캡처하세요.
