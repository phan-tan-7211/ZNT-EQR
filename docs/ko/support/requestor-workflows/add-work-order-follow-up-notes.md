**대상:** 요청자  
**최종 검토일:** 2026-07-03

작업 지시를 제출한 뒤 또는 작업 지시가 완료된 뒤에 문서를 첨부해야 할 때는 공개 메모를 사용하세요.

## 1. 작업 지시 열기

**작업 지시**로 이동하여 소속 팀을 위해 직접 생성했거나 요청한 작업 지시를 엽니다.

## 2. 공개 메모 추가

**메모 및 업데이트**까지 스크롤한 다음 **메모 추가**를 선택합니다.

- 업데이트 내용을 입력합니다(예: 구매 주문 번호 또는 승인 참조 번호).
- 필요하면 사진을 첨부할 수 있습니다.
- 요청자는 **공개** 메모만 추가할 수 있습니다. 비공개/내부 메모는 매니저와 기술자만 사용할 수 있습니다.

## 3. 완료된 작업 지시

작업 지시가 **완료됨**으로 표시된 후에도 공개 메모를 추가할 수 있으므로, 청구나 승인 관련 증빙을 나중에 남길 수 있습니다.

**취소됨** 상태의 작업 지시에는 메모를 추가할 수 없습니다.
