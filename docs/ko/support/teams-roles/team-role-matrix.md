**대상:** 모든 사용자  
**최종 검토일:** 2026-05-01
모든 팀에는 해당 팀에 한정된 동일한 네 가지 역할이 있습니다. 한 사용자가 팀마다 다른 팀 역할을 가질 수 있습니다.

## 1. 매니저

**내부 리더.**

- 팀 구성원을 추가하거나 제거합니다.
- 작업 지시를 배정합니다.
- 팀의 설비 기록을 관리합니다.
- 작업 지시를 전체 수명 주기에 걸쳐 진행시킵니다.

## 2. 기술자

**작업을 수행하는 내부 직원.**

- 배정된 작업 지시의 상태를 업데이트합니다.
- 메모, 사진, 작업 시간을 추가합니다.
- 재고 부품을 사용합니다.
- 다른 사람에게 작업을 배정하거나 팀 구성원을 관리할 수는 없습니다.

## 3. 요청자

**신뢰할 수 있는 고객 또는 설비 소유자.**

- 설비 QR 코드를 스캔하고 새 작업 요청을 제출합니다.
- 소속 팀의 설비와 작업 지시를 봅니다.
- 제출 후에는 작업 지시를 수정하거나 취소할 수 없습니다.

## 4. 조회자

**읽기 전용 접근.**

- 설비 상세 정보와 작업 지시 이력을 봅니다.
- 아무것도 생성하거나 수정할 수 없습니다.
- 내용 확인만 필요한 감사 담당자, 회계 담당자 또는 고객사 직원에게 적합합니다.
