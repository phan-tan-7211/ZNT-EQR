# 팀 및 역할

조직과 팀의 역할 계층을 이해하고 누가 어떤 역할을 맡아야 할지 결정합니다.

## 문서

- [조직 역할 자세히 알아보기](./organization-roles) — 소유자, 관리자, 구성원이 조직 수준에서 할 수 있는 일과 각 역할이 주로 누구에게 부여되는지 설명합니다.
- [팀 역할별 권한 상세 안내](./team-role-matrix) — 네 가지 팀 역할(매니저, 기술자, 요청자, 조회자)과 각 역할이 팀 안에서 할 수 있는 일을 설명합니다.
- [예시: "Apex Repair Services"](./apex-example-hierarchy) — 서비스 제공업체가 고객을 팀에 어떻게 대응시키고 누구에게 어떤 역할을 부여하는지 보여 주는 현실적인 고객 사례입니다.
- [팀 구성원 추가 또는 제거하기](./add-team-member) — 기존 조직 구성원을 팀에 초대하고, 알맞은 팀 역할을 선택하고, 담당이 바뀌면 팀에서 제거합니다.
- [팀 전용 보기 선택하기](./team-views) — 팀을 내부 전문가 그룹, 부서 또는 외부 고객 계정으로 표현하고, 모든 사람에게 표시될 기본 보기를 설정합니다.
- [팀과 역할에 관한 자주 묻는 질문](./multi-team-questions) — 여러 팀 소속과 고객 접근 권한에 관해 가장 자주 묻는 질문에 간단히 답합니다.
