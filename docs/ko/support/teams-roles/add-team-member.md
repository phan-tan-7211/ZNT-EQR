**대상:** 매니저, 관리자, 소유자  
**최종 검토일:** 2026-05-01

::: info 필요 권한
조직 소유자와 관리자는 모든 팀을 관리할 수 있습니다. 팀 매니저는 자신의 팀을 관리할 수 있습니다.
:::

## 1. 팀 열기

사이드바에서 팀을 열고 수정하려는 팀을 클릭합니다.

## 2. 구성원 추가 클릭

선택 목록에는 아직 이 팀에 속하지 않은 모든 조직 구성원이 표시됩니다.

## 3. 팀 역할 선택

**매니저**, **기술자**, **요청자** 또는 **조회자**를 선택합니다. 대상자가 고객이라면 요청자 또는 조회자를 선택하고, 내부 직원이라면 매니저 또는 기술자로 지정하세요.

## 4. 저장

새 구성원은 즉시 팀의 설비를 볼 수 있으며, 역할이 허용하는 작업을 수행할 수 있습니다.

## 5. 구성원 제거

팀 페이지의 구성원 목록에서 해당 구성원의 행을 열고 제거를 선택합니다. 팀 설비에 대한 접근 권한은 즉시 사라지지만 조직에는 그대로 남습니다.
