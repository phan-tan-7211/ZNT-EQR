::: info 필요 조건
작업 지시에 예방정비(PM) 체크리스트가 첨부되어 있어야 합니다. 작업 지시를 생성할 때 첨부하거나 진행 중인 작업에 나중에 추가할 수 있습니다. [진행 중인 작업 지시에서 예방정비 템플릿 관리하기](../work-orders/manage-pm-template-on-work-order)를 참고하세요.
:::

## 1. PM 체크리스트가 있는 작업 지시 열기

작업 지시에서 본인에게 배정된 PM 사용 작업을 선택합니다. 작업 지시 상세 정보 아래에 예방 정비 점검표 섹션이 표시됩니다.

![작업 지시의 PM 체크리스트 섹션](https://wgynakhoppqkrutnslmv.supabase.co/storage/v1/object/public/docs-media/support/technician-field-work/desktop/08-pm-checklist-section.png)

![PM 체크리스트로 이동할 수 있는 모바일 작업 지시 상세](https://wgynakhoppqkrutnslmv.supabase.co/storage/v1/object/public/docs-media/support/technician-field-work/mobile/02-mobile-work-order-summary.png)

## 2. 상태가 양호한 항목은 모두 OK로 설정 누르기

모두 OK로 설정 버튼을 누르면 모든 항목이 한 번에 양호로 표시되므로 예외 항목에만 집중하면 됩니다.

## 3. 예외 사항 표시

조치가 필요한 항목마다 상태(주의 필요, 긴급 등)를 변경하고, 문제를 설명하는 짧은 메모를 추가하고, 문제를 보여 주는 사진을 첨부합니다. 예외 사항은 매니저가 분류해 처리하는 후속 작업의 근거가 됩니다.

## 4. 진행 상황 저장

변경 사항은 작업하는 동안 자동으로 저장되며, 변경 사항 저장을 눌러 직접 저장할 수도 있습니다. 작업이 중단되었다면 나중에 돌아와서 마무리하세요. 체크리스트는 항목별로 상태를 유지합니다.
