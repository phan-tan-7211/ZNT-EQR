## 문서

![설비에서 작업 지시 생성](https://wgynakhoppqkrutnslmv.supabase.co/storage/v1/object/public/docs-media/support/technician-field-work/desktop/02-create-work-order-dialog.png)

![모바일 빠른 작업 시트](https://wgynakhoppqkrutnslmv.supabase.co/storage/v1/object/public/docs-media/support/technician-field-work/mobile/03b-mobile-quick-actions-sheet.png)

- [휴대폰으로 설비 QR 코드 스캔하기](./scan-equipment-qr) — 휴대폰 기본 카메라 앱으로 올바른 조직이 이미 선택된 상태에서 ZNTEQR의 설비 기록을 엽니다.
- [설비에서 작업 지시 생성하기](./create-work-order-from-equipment) — 설비 기록에서 바로 새 작업 지시를 시작하면 올바른 설비와 팀에 미리 연결됩니다.
- [작업 지시 상태 업데이트하기](./update-work-order-status) — 적절한 권한 확인을 거쳐 작업 지시를 제출됨 → 접수됨 → 배정됨 → 진행 중 → 완료됨 순서로 진행합니다.
- [작업 지시에 메모와 사진 추가하기](./add-notes-and-photos) — 발견한 내용과 수행한 작업을 기록하고 작업 전/중/후 사진을 첨부합니다. 모두 설비의 이미지 갤러리에서 볼 수 있습니다.
- [PM 체크리스트 완료하기](./pm-checklist) — 예방정비 항목을 체크하고, 예외 사항을 표시하고, 후속 조치가 필요한 항목에 증빙 사진을 첨부합니다.
- [작업 지시에서 재고 부품 사용 처리하기](./consume-inventory-on-wo) — 수리에 사용한 부품을 기록하면 재고가 자동으로 차감되고 비용이 청구서에 반영됩니다.
- [모바일 빠른 작업 사용하기](./mobile-quick-actions) — 설비 및 작업 지시 페이지에서 엄지손가락이 닿는 버튼 하나로 QR 코드, 상태 변경, 메모, 내보내기를 모은 드로어를 엽니다.
