::: info 필요 조건
휴대폰(작은 화면)에서 사용할 수 있습니다. 각 작업에는 평소 권한이 그대로 적용됩니다.
:::

모바일에서 ZNTEQR은 각 페이지의 상황별 작업을 하나의 **빠른 액세스 버튼** 뒤에 모아 두므로, 한 손으로 사다리를 잡은 채 메뉴를 뒤질 필요가 없습니다.

## 설비 상세

설비 기록의 오른쪽 아래에 있는 둥근 **QR 버튼**을 누르면 빠른 작업 드로어가 열립니다.

- **QR 코드** — 설비 스캔용 QR을 표시하고, 사용 설정된 일일 점검 체크리스트마다 항목을 하나씩 보여 주므로 작업자에게 알맞은 코드를 건넬 수 있습니다.
- **작업 지시** — 이 설비에 미리 연결된 새 작업 지시를 시작합니다. 제목 아래 드롭다운에서 예방정비 템플릿을 선택하거나 **없음**으로 그대로 둡니다.
- **메모** — 메모 입력 화면으로 바로 이동합니다.

## 작업 지시 상세

작업 지시에서는 현장 도구(상태 변경, 메모, 사진, 타이머)가 하단 작업 트레이에 있습니다. 트레이의 **빠른 작업** 버튼, 또는 트레이가 숨겨져 있을 때 표시되는 둥근 번개 버튼을 누르면 다음 항목이 담긴 드로어가 열립니다.

![작업 지시의 모바일 빠른 작업 시트](https://wgynakhoppqkrutnslmv.supabase.co/storage/v1/object/public/docs-media/support/technician-field-work/mobile/03b-mobile-quick-actions-sheet.png)

![상태 작업이 표시된 데스크톱 작업 지시 상세](https://wgynakhoppqkrutnslmv.supabase.co/storage/v1/object/public/docs-media/support/technician-field-work/desktop/05-status-in-progress.png)

- 이 작업 지시에 **다음으로 해당하는 상태 작업**(접수, 작업 시작, 완료, 재개 또는 체크리스트 계속).
- **메모 추가 / 사진 추가** 바로가기.
- **작업 지시 QR 코드 표시** — QR을 표시해 다른 기기에서 이 작업 지시를 바로 열거나 현장 작업표를 인쇄할 수 있습니다.
- **내보내기** — PDF, 스프레드시트, 문서 다운로드와 함께, 해당 연동이 연결되어 있으면 Google Drive 및 QuickBooks 옵션이 표시됩니다(각각 별도 섹션으로 묶임).

## 목록에는 추가 버튼이 그대로 있습니다

설비, 작업 지시, 재고 목록에는 새 기록을 만드는 둥근 **+** 버튼이 그대로 유지됩니다. 빠른 작업 드로어는 맥락이 중요한 상세 페이지에서만 나타납니다.
