**대상:** 관리자, 소유자, 매니저  
**최종 검토일:** 2026-07-04

::: info 필요 권한
소유자, 관리자 또는 지정된 부품 관리자여야 합니다.
:::

## 1. 재고 열기

사이드바에서 재고를 선택합니다. 목록에는 조직 전체의 모든 품목이 표시되며 팀별로 필터링할 수 있습니다.

## 2. 품목 추가 클릭

필수 항목과 선택 항목이 있는 양식이 열립니다. 수십 개 또는 수백 개의 부품을 한 번에 가져오려면 재고 일괄 편집을 사용하세요.


## 3. 기본 정보 입력

- **이름** — 알아보기 쉬운 이름을 입력합니다. 예: "오일 필터 - CAT 320".
- **SKU** — 내부 부품 번호입니다.
- **외부 ID** — 스캔에 사용하는 제조사 바코드 또는 UPC입니다.
- **설명** — 현장 직원이 부품을 식별하는 데 도움이 되는 선택 정보입니다.

## 4. 재고 수준 설정

- **보유 수량** — 현재 재고 수량입니다.
- **재고 부족 기준** — 재고가 이 숫자 이하로 떨어지면 ZNTEQR이 부품 관리자에게 알립니다.
- **기본 단가** — 작업 지시 비용을 채우는 데 사용됩니다.
- **위치** — 선택 사항인 **위치 이름** 별칭입니다(예: "선반 A-3"). 이 라벨은 지도에 핀을 표시하지 않습니다. 구조화된 **보관 주소**는 품목 상세 페이지에서 설정하거나 [조직의 재고 기본 위치](../admin-integrations/organization-settings)를 상속받으세요.

## 5. 저장하고 QR 코드 인쇄

품목을 저장합니다. 상세 페이지에서 QR 아이콘을 눌러 보관함에 붙일 라벨을 인쇄하면 기술자가 작업하러 가는 길에 스캔할 수 있습니다.
