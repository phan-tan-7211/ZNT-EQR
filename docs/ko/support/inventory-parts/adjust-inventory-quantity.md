**대상:** 매니저, 관리자, 소유자  
**최종 검토일:** 2026-05-01

::: info 필요 권한
소유자, 관리자 또는 지정된 부품 관리자여야 합니다.
:::

## 1. 품목 상세 페이지 열기

재고에서 품목을 클릭하여 상세 페이지를 봅니다. 현재 재고는 페이지 상단에 표시됩니다.

## 2. 수량 조정 클릭

간단한 조정을 위한 +1 / -1 빠른 버튼이 있는 조정 대화 상자가 열립니다.

## 3. 재고 추가 또는 사용

- **1개 추가 / 1개 사용** — 한 단위씩 빠르게 조정합니다.
- **더 추가 / 더 사용** — 원하는 수량을 직접 입력합니다.
- **사유** — 감사 추적을 위한 선택 메모입니다.

## 4. 거래 내역 검토

거래 내역 탭으로 전환하면 모든 조정 내역을 시각, 사용자, 수량 변화, 사유와 함께 볼 수 있습니다. 작업 지시에서 사용한 수량도 여기에 표시됩니다.

::: tip 참고
ZNTEQR은 재고 조정 내역을 절대 삭제하지 않습니다. 실수를 바로잡으려면 명확한 사유와 함께 상쇄하는 조정을 입력하세요.
:::
