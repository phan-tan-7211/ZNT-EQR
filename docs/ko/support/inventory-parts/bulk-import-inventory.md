**대상:** 관리자, 소유자  
**최종 검토일:** 2026-05-01

::: info 필요 권한
소유자, 관리자 또는 지정된 부품 관리자여야 합니다.
:::

## 1. 재고 → 재고 일괄 편집 열기

재고 목록에서 일괄 추가 / 편집 버튼을 사용합니다(또는 /dashboard/inventory/bulk로 직접 이동합니다).

## 2. 편집할 행 선택

행을 한 번 클릭하여 선택합니다. 셀을 두 번 클릭하면 이름, SKU, 위치, 수량, 기준, 기본 단가 같은 값을 편집할 수 있습니다.

## 3. 선택한 행에 변경 사항 적용

다중 선택 편집을 사용하여 여러 품목에 같은 값을 한 번에 적용한 다음, 저장하기 전에 강조 표시된 변경된 셀을 검토합니다.

## 4. 커밋하고 확인

업데이트 저장을 클릭하여 대기 중인 모든 편집 내용을 저장합니다. 유효성 검사나 업데이트에 실패한 행이 있으면 재고 일괄 편집 화면에서 실패 내역을 알려 주므로 해당 품목만 수정하면 됩니다.
