**대상:** 관리자, 소유자  
**최종 검토일:** 2026-07-06

::: info 필요 권한
조직 소유자 또는 관리자여야 합니다.
:::

기본적으로 소유자와 관리자만 재고를 보거나 편집할 수 있습니다. **부품 접근 권한** 패널에서는 두 가지 수준의 접근 권한을 부여할 수 있어, 관리자 권한을 열어 주지 않고도 정비 현장 업무가 원활하게 돌아갑니다.

- **부품 관리자**는 재고 품목을 생성, 편집, 삭제하고 수량을 조정할 수 있습니다.
- **부품 조회 담당자**는 재고를 보고 부품 조회를 사용할 수 있지만 품목을 편집할 수는 없습니다.

두 권한 중 어느 것도 받지 않은 구성원은 재고에 전혀 접근할 수 없습니다.

## 1. 재고 → 부품 접근 권한 열기

재고에서 품목 추가 옆에 있는 **부품 접근 권한** 버튼을 클릭합니다. 휴대폰에서는 재고 목록 하단의 **부품 접근 권한 업데이트** 링크를 사용하세요.

## 2. 역할에 구성원 추가

각 역할 섹션에는 **추가** 버튼이 있으며, 이 버튼을 누르면 모두 선택 / 모두 해제 / 선택 반전 컨트롤이 있는 검색 가능한 구성원 선택기가 열립니다. 구성원을 한 명 이상 선택하고 확인하면 접근 권한이 즉시 적용됩니다.

## 3. 필요할 때 접근 권한 제거

두 섹션 중 해당 구성원의 행에 있는 휴지통 아이콘을 클릭하고 확인합니다. 해당 구성원의 접근 권한은 없음(또는 남아 있는 다른 권한)으로 되돌아갑니다.

::: tip 구성원 페이지에서도 설정 가능
부품 관리자 및 부품 사용자 토글은 **조직 → 구성원**에서도 구성원별로 표시되므로, 구성원의 다른 권한과 함께 재고 접근 권한을 검토할 수 있습니다.
:::
