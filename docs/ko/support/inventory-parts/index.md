# 재고 및 부품

부품을 추적하고, 부품 관리자에게 재고 관리를 위임하고, 호환 가능한 부품을 정리합니다.

## 문서

- [재고 품목 추가](./add-inventory-item) — 재고 수준, 호환성 규칙, QR 코드를 갖춘 새 부품을 만들어 기술자가 보관함에서 바로 스캔할 수 있게 합니다.
- [재고 수량 조정](./adjust-inventory-quantity) — 재고를 추가하거나 사용하고, 사유를 기록하고, 거래 내역을 검토합니다.
- [부품 접근 권한으로 재고 관리 위임하기](./parts-managers-setup) — 누구도 관리자로 만들지 않고 부품 관리자(편집)와 부품 조회 담당자(보기 + 부품 조회) 권한을 부여합니다.
- [대체 부품 그룹 만들기](./alternate-groups-setup) — 서로 호환되는 부품을 정의하여 주 부품의 재고가 없을 때 기술자가 대체할 수 있게 합니다.
- [재고 일괄 편집](./bulk-import-inventory) — 품목을 하나씩 여는 대신 하나의 그리드에서 여러 기존 재고 기록을 한꺼번에 업데이트합니다.
- [부품 조회로 부품 찾기](./part-lookup-search) — 재고, 대체 부품 그룹, 상호 참조 번호를 한곳에서 검색합니다.
