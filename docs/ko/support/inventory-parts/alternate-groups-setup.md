**대상:** 관리자, 소유자, 매니저  
**최종 검토일:** 2026-05-01
대체 부품 그룹은 서로 대체할 수 있는 부품을 묶어 둔 것입니다. 예를 들어 OEM 필터와 애프터마켓 필터가 있습니다. 그룹에 속한 어떤 부품 번호로 검색하더라도 현재 사용할 수 있는 모든 대체품이 표시됩니다.

## 1. 대체 부품 열기

사이드바의 설비 아래에서 대체 부품을 클릭합니다. 모든 그룹이 검증 배지(미검증, 검증됨, 사용 중단)와 함께 표시됩니다.

## 2. 새 대체 부품 그룹 클릭

그룹에 'Oil Filter - CAT D6T Compatible'처럼 알아보기 쉬운 이름을 지정하고, 필요하면 간단한 설명을 추가합니다.

## 3. 재고 품목 추가

그룹을 열고 품목 추가를 클릭한 다음 서로 대체할 수 있는 재고 품목을 선택합니다. 하나를 대표 부품으로 표시하면 검색 결과에서 강조됩니다.

## 4. OEM 및 애프터마켓 부품 번호 추가

부품 번호 추가를 클릭하여 OEM, 애프터마켓, 제조사, 상호 참조 코드를 등록합니다. 부품 조회는 이 중 어느 것과도 일치하는 결과를 찾아 줍니다.

## 5. 그룹을 검증됨으로 표시

제조사 자료나 검증된 상호 참조 자료와 대체품을 대조해 확인했다면 그룹을 편집하여 상태를 검증됨으로 변경합니다. 배지가 녹색으로 바뀌고 기술자가 신뢰 수준을 확인할 수 있습니다.

::: tip 참고
어떻게 검증했는지 메모 필드에 기록해 두세요. 예: OEM 상호 참조, 현장 테스트, 서비스 공지 번호.
:::
