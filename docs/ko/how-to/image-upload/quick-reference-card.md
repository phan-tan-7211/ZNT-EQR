# ZNTEQR 이미지 업로드 빠른 참조

## 빠른 시작

### 1. 설비 열기
- **QR 코드**: 모바일 앱으로 스캔합니다
- **직접 이동**: 설비 → 설비 찾기

### 2. 작업 지시 만들기
- **"작업 지시"** 탭을 클릭합니다
- **"작업 지시 생성"** 을 클릭합니다
- 제목, 우선순위, 설명을 입력합니다
- 필요하면 **"예방 정비 점검 목록 포함"** 을 선택합니다

### 3. 이미지 업로드
- **"메모 추가"** 섹션으로 스크롤합니다
- 메모 내용과 작업 시간을 입력합니다
- **"파일 선택"** 을 클릭해 이미지를 고릅니다
- 내부용이라면 **"비공개 메모"** 를 켭니다
- **"메모 추가"** 를 클릭해 저장합니다

### 4. 대표 이미지 설정
- **"이미지"** 탭으로 이동합니다
- 원하는 이미지를 찾습니다
- **"대표 이미지로 설정"** 을 클릭합니다

## 예방정비(PM) 점검 목록 빠른 작업

### 점검 목록 초기화
- **"기본 점검 목록 초기화"** 버튼을 클릭합니다
- 섹션별로 모든 항목을 확인합니다

### 항목 완료
- **모두 OK로 설정**: 상태가 양호할 때 쓰는 빠른 작업
- **개별 항목**: 상태(1-5)를 선택하고 메모를 추가합니다
- **사진 업로드**: 문제를 이미지로 보여 줍니다
- **변경 사항 저장**: 섹션을 마칠 때마다 저장합니다

### 상태 등급
- **1** = 매우 좋음 ✅
- **2** = 양호 ✅
- **3** = 보통 ⚠️
- **4** = 나쁨 ❌
- **5** = 심각 🚨

## 작업 지시 관리

### 상태 변경
- 작업 지시 상세를 엽니다
- 상태 드롭다운을 클릭합니다
- 선택: 대기 중 → 진행 중 → 완료
- 상태 변경 메모를 추가합니다

### 부품/비용 추가
- **"비용"** 섹션으로 이동합니다
- **"비용 항목 추가"** 를 클릭합니다
- 이름, 수량, 단가를 입력합니다
- 설명을 추가합니다

### 비공개 메모와 공개 메모
- **비공개**: 켜면 내부용으로만 사용됩니다
- **공개**: 끄면 고객에게 표시됩니다

## 이미지 요건

### 지원 형식
- JPG, PNG, GIF
- 이미지당 최대 10MB
- 메모당 최대 10장

### 권장 사항
- 선명하고 밝게 촬영합니다
- 여러 각도에서 촬영합니다
- 설명 메모를 추가합니다
- 가장 잘 나온 이미지를 대표 사진으로 설정합니다

## 문제 해결

### 이미지가 업로드되지 않을 때
- 파일 형식을 확인합니다(JPG/PNG/GIF)
- 파일 크기를 확인합니다(<10MB)
- 인터넷 연결을 확인합니다
- 더 작은 이미지로 시도합니다

### 이미지가 갤러리에 없을 때
- 페이지를 새로 고칩니다
- 작업 지시가 저장되었는지 확인합니다
- 몇 분 기다립니다
- 관리자에게 문의합니다

### 예방정비(PM) 점검 목록 문제
- 인터넷 연결을 확인합니다
- 수동으로 저장합니다
- 오류 메시지가 있는지 확인합니다
- 페이지를 새로 고쳐 봅니다
