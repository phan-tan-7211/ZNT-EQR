# 설비 이미지 업로드 문서

> **기준 자료:** [도움말 센터](/ko/support/technician-field-work/)
> — **작업 지시에 메모와 사진 추가하기** 및 **예방정비(PM) 점검 목록 완료하기**를 참고하세요.

이 디렉터리에는 빠른 참조 카드와 인쇄용 기술자 가이드가 들어 있습니다.
도움말 센터 문서와 내용이 일치하도록 유지하세요.

## 문서 파일

- **[기술자용 이미지 업로드 가이드](/ko/how-to/image-upload/technician-image-upload-guide)** — 작업 지시와
  사진 등록의 핵심 흐름을 번호 순서대로 설명한 가이드입니다.
  앱 내 문서와 같은 내용이지만 인쇄하거나 신규 입사자에게 공유하기가 더 쉽습니다.
- **[빠른 참조 카드](/ko/how-to/image-upload/quick-reference-card)** — 현장 기술자를 위한
  코팅 카드 형식의 요약표입니다.

## 대상 독자

- 현장에서 작업 지시를 수행하는 **기술자**.
- 신규 기술자를 교육하는 **팀 리더**.

## 관련 문서

- [워크플로](/ko/guides/workflows) — 작업 지시 수명 주기와 권한 상세 정보.
- [권한(RBAC)](/ko/guides/permissions) — 공식 RBAC 매트릭스.
- [도움말 센터](/ko/support/) — 공식 단계별 가이드.
