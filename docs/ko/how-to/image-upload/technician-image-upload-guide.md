# 기술자 가이드: 설비 기록에 이미지 업로드하기

## 개요

사진은 작업 지시 메모에 저장됩니다. 설비의 이미지 탭에도 표시됩니다.

## 사전 준비

- ZNTEQR™ 모바일 앱 또는 웹 인터페이스에 접속할 수 있어야 합니다
- 설비 QR 코드를 스캔했거나 설비 ID를 알고 있어야 합니다
- 업로드할 카메라 또는 이미지 파일이 준비되어 있어야 합니다
- 적절한 권한이 있는 유효한 기술자 계정이 필요합니다

## 단계별 절차

### 1단계: 설비 기록 열기

1. ZNTEQR™ 모바일 앱으로 설비에 붙은 **QR 코드를 스캔**합니다
2. 설비 ID를 알고 있다면 설비 페이지로 **직접 이동**해도 됩니다
3. 설비 페이지에 해당 장비의 기본 정보가 표시됩니다

> **그림 1:** 기본 정보가 표시된 초기 설비 페이지.
> *(이 가이드의 스크린샷은 `docs/how-to/image-upload/screenshots/` 아래에 있습니다. 게시된 사이트에 그림을 넣어야 한다면 폴더 README에 따라 PNG 파일을 추가하세요.)*

### 2단계: 작업 지시 만들기

1. 설비 페이지에서 **"작업 지시"** 탭을 클릭합니다
2. **"작업 지시 생성"** 또는 **"첫 작업 지시 생성"** 버튼을 클릭합니다
3. 작업 지시 정보를 입력합니다.
   - **제목**: 내용을 알 수 있는 제목을 입력합니다(예: "유압 시스템 수리 - 트랙 교체")
   - **우선순위**: 알맞은 우선순위를 선택합니다
   - **설명**: 필요한 작업을 자세히 적습니다

> **그림 2:** 새 작업 지시 만들기.
> *(스크린샷 경로: `screenshots/03-work-order-creation-form.png` — 선택 자료.)*

### 3단계: 메모와 함께 이미지 업로드하기

1. 작업 지시를 만든 뒤 **"첫 메모 추가"** 섹션까지 아래로 스크롤합니다
2. 메모 정보를 입력합니다.
   - **메모 내용**: 발견한 내용, 수행한 작업, 중요한 관찰 사항을 적습니다
   - **작업 시간**: 작업에 들인 시간을 입력합니다
   - **비공개 메모**: 이 메모를 본인만 볼 수 있게 하려면 켭니다

3. **이미지 업로드**:
   - **"이미지(선택 사항)"** 섹션에서 **"파일 선택"** 을 클릭합니다
   - 기기에서 이미지를 하나 이상 선택합니다
   - 메모를 저장하면 이미지가 자동으로 업로드됩니다

> **그림 3:** 상세한 메모와 함께 이미지 업로드하기.
> *(스크린샷 경로: `screenshots/09-notes-section-with-image-upload.png` — 선택 자료.)*

### 4단계: 설비 대표 이미지 설정하기

1. 이미지를 업로드한 뒤 설비 페이지의 **"이미지"** 탭으로 이동합니다
2. 대표 이미지로 사용할 이미지를 찾습니다
3. 원하는 이미지에서 **"대표 이미지로 설정"** 버튼을 클릭합니다
4. 이제 해당 이미지가 설비의 대표 사진으로 표시됩니다

> **그림 4:** 이미지를 설비 대표 사진으로 설정하기.
> *(스크린샷 경로: `screenshots/final-images-tab-state.png` — 선택 자료.)*

## 예방정비(PM) 점검 목록 사용하기

### 5단계: 예방 정비 점검 목록이 포함된 작업 지시 만들기

1. 작업 지시를 만들 때 **"예방 정비 점검 목록 포함"** 옵션을 선택합니다
2. 예방정비 템플릿을 선택합니다(예: "Forklift PM Checklist")
3. 작업 지시에 정비 점검 목록이 포함됩니다

> **그림 5:** 예방 정비 점검 목록이 포함된 작업 지시 만들기.
> *(스크린샷 경로: `screenshots/04-work-order-form-with-pm-checklist.png` — 선택 자료.)*

### 6단계: 예방 정비 점검 목록 항목 완료하기

1. 작업 지시 상세에서 **"예방 정비 점검 목록"** 섹션으로 스크롤합니다
2. **"모두 OK로 설정"** 을 클릭하면 모든 항목을 빠르게 정상으로 표시할 수 있습니다
3. 주의가 필요한 항목은 다음과 같이 처리합니다.
   - 알맞은 상태를 선택합니다(주의 필요, 심각 등)
   - 문제를 설명하는 자세한 메모를 추가합니다
   - 문제를 보여 주는 사진을 업로드합니다

> **그림 6:** 메모와 사진으로 예방 정비 점검 목록 항목 완료하기.
> *(스크린샷 경로: `screenshots/06-pm-checklist-section.png` — 선택 자료.)*

### 7단계: 진행 상황 저장하기

1. 점검 목록 항목을 수정한 뒤 **"변경 사항 저장"** 을 클릭합니다
2. 시스템이 진행 상황을 자동으로 저장합니다
3. 나중에 점검 목록으로 돌아와 작업을 이어갈 수 있습니다

> **그림 7:** 예방 정비 점검 목록 진행 상황 저장하기.
> *(스크린샷 경로: `screenshots/08-pm-checklist-after-set-all-ok.png` — 선택 자료.)*

## 작업 지시 상태 관리하기

### 8단계: 작업 지시 상태 업데이트하기

1. 작업 지시 상세에서 **"상태"** 섹션을 찾습니다
2. 상태 드롭다운을 클릭해 작업 지시 상태를 변경합니다.
   - **대기 중**: 작업 지시가 생성되었지만 아직 시작되지 않음
   - **진행 중**: 작업이 현재 수행되고 있음
   - **완료**: 모든 작업이 끝남
   - **취소됨**: 작업 지시가 취소됨

> **그림 8:** 작업 지시 상태 업데이트하기.
> *(스크린샷 경로: `screenshots/work-order-complete-view.png` — 선택 자료.)*

## 항목과 비용 추가하기

### 9단계: 부품과 비용 추가하기

1. 작업 지시 상세에서 **"비용"** 섹션으로 스크롤합니다
2. **"비용 항목 추가"** 를 클릭해 부품이나 서비스를 추가합니다
3. 상세 정보를 입력합니다.
   - **항목 이름**: 부품 또는 서비스의 이름
   - **수량**: 사용한 개수
   - **단가**: 항목당 비용
   - **설명**: 추가 정보

> **그림 9:** 작업 지시에 부품과 비용 추가하기.
> *(스크린샷 경로: `screenshots/work-order-add-note-form.png` — 선택 자료.)*

## 비공개 메모

### 10단계: 비공개 메모 추가하기

1. 메모를 추가할 때 **"비공개 메모"** 옵션을 켭니다
2. 비공개 메모는 본인과 다른 기술자에게만 표시됩니다
3. 비공개 메모는 다음과 같은 경우에 사용하세요.
   - 내부 관찰 사항
   - 개인적인 메모
   - 민감한 정보

> **그림 10:** 고객에게 보이지 않는 비공개 메모 추가하기.
> *(스크린샷 경로: `screenshots/note-with-uploaded-image.png` — 선택 자료.)*

## 설비의 모든 이미지 보기

### 11단계: 설비 이미지 갤러리 열기

1. 설비 페이지에서 **"이미지"** 탭으로 이동합니다
2. 작업 지시와 설비 메모를 통해 업로드된 모든 이미지를 확인합니다
3. 이미지는 날짜와 출처별로 정리됩니다
4. 이미지를 클릭하면 전체 크기로 볼 수 있습니다

> **그림 11:** 갤러리에서 설비의 모든 이미지 보기.
> *(스크린샷 경로: `screenshots/images-tab-with-both-images.png` — 선택 자료.)*

## 문제 해결

### 이미지가 갤러리에 표시되지 않을 때

작업 지시를 통해 업로드한 이미지가 설비의 이미지 탭에 표시되지 않는다면 다음을 확인하세요.

1. 작업 지시가 제대로 저장되었는지 확인합니다
2. 이미지 업로드가 정상적으로 완료되었는지 확인합니다
3. 페이지를 새로 고쳐 최신 이미지를 확인합니다
4. 문제가 계속되면 관리자에게 문의합니다

### 업로드 문제

이미지 업로드가 잘 되지 않는다면 다음을 확인하세요.

1. 인터넷 연결을 확인합니다
2. 이미지가 지원 형식(JPG, PNG, GIF)인지 확인합니다
3. 업로드가 느리면 이미지 파일 크기를 줄여 봅니다
4. 문제가 계속되면 지원팀에 문의합니다

## 권장 사항

1. 이미지에는 **항상 설명 메모를 추가하세요**
2. 문제가 잘 보이도록 **선명하고 밝은 사진을 사용하세요**
3. 복잡한 문제는 **여러 각도에서 촬영하세요**
4. 쉽게 식별할 수 있도록 **가장 잘 나온 이미지를 대표 사진으로 설정하세요**
5. 민감한 정보에는 **비공개 메모를 사용하세요**
6. 진행 내용을 잃지 않도록 **작업을 자주 저장하세요**
