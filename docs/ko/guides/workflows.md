# 워크플로 참조

이 문서는 ZNTEQR의 작업 지시 수명 주기, 역할별 권한, 상태 전환 규칙을 정리한
공식 기술 참조 문서입니다. 최종 사용자를 위한 단계별 안내서가 아닙니다.
단계별 안내는 **ZNTEQR 도움말 센터**
**`https://eqrdocs.zinitek.com/support/`** 에 있습니다. 로그인한 사용자는
**`https://eqr.zinitek.com/dashboard/support`** 에서 문제를 신고합니다.

## 사용자용 안내서를 찾는 곳

- **도움말 센터** — `https://eqrdocs.zinitek.com/support/` (역할과 워크플로별로 정리된
  단계별 가이드의 기준 자료).
- **[이미지 업로드 빠른 참조 카드](../how-to/image-upload/quick-reference-card.md)**
  — 현장 기술자를 위한 한 페이지 요약표.
- **[기술자용 이미지 업로드 가이드](../how-to/image-upload/technician-image-upload-guide.md)**
  — 작업 지시와 사진 등록 흐름을 번호 순서대로 설명한 가이드.

이 문서의 나머지 부분은 전체 수명 주기와 권한 구성을 한곳에서 확인해야 하는
개발자, 관리자, 지원 엔지니어를 위한 참조 자료로 구성되어 있습니다.

## 작업 지시 수명 주기

### 상태 흐름

작업 지시는 일곱 가지 상태를 거칩니다.

1. **제출됨** — 생성 시의 초기 상태입니다.
2. **수락됨** — 검토를 거쳐 일정 수립이 승인된 상태입니다.
3. **배정됨** — 특정 기술자 또는 팀에 넘겨진 상태입니다.
4. **진행 중** — 작업이 시작된 상태입니다.
5. **보류** — 일시 중지된 상태입니다(부품, 고객 또는 출입 대기).
6. **완료** — 종료 상태입니다. 전환 시 `completed_date`와 `completed_day`가
   자동으로 설정됩니다.
7. **취소됨** — 종료 상태입니다. `completed_day`는 `NULL`로 유지됩니다.

### 상태 전환

| 현재 상태 | 다음 상태 | 허용 역할 | 비고 |
|---------|-------------|---------------|-------|
| 제출됨 | 수락됨, 취소됨 | 매니저, 관리자, 소유자 | 최초 검토 |
| 수락됨 | 배정됨, 취소됨 | 매니저, 관리자, 소유자 | 배정 준비 완료 |
| 배정됨 | 진행 중, 보류, 취소됨 | 매니저, 관리자, 소유자, 배정된 기술자 | 작업 시작 가능 |
| 진행 중 | 완료, 보류, 취소됨 | 매니저, 관리자, 소유자, 배정된 기술자 | 작업 수행 단계 |
| 보류 | 진행 중, 취소됨 | 매니저, 관리자, 소유자, 배정된 기술자 | 재개 또는 종료 |
| 완료 | (종료) | — | 최종 |
| 취소됨 | (종료) | — | 최종 |

### 상태 변경 권한(요약)

```
Submitted → Accepted:      Manager+
Accepted → Assigned:       Manager+
Assigned → In Progress:    Manager+ or Assigned Technician
In Progress → Completed:   Manager+ or Assigned Technician
Any → On Hold:             Manager+ or Assigned Technician
Any → Cancelled:           Manager+
```

## 역할과 권한

이 섹션에서는 작업 지시 접근을 결정하는 역할별 권한을 요약합니다.
설비, 재고, 구성원 관리를 포함한 전체 RBAC 매트릭스는
[권한](./permissions.md)을 참고하세요.

### 조직 수준 역할

| 역할 | 범위 | 작업 지시 권한 |
|------|-------|-------------------------|
| 소유자 | 조직 전체 | 모든 작업 지시를 생성, 조회, 수정, 삭제, 배정하고 상태를 변경할 수 있습니다. |
| 관리자 | 조직 전체 | 소유자와 같지만 조직 삭제와 소유권 이전은 할 수 없습니다. |
| 구성원 | 조직(제한적) | 작업 지시를 생성하고, 자신이 만들었거나 배정받은 작업 지시와 팀 작업 지시를 조회합니다. |

### 팀 수준 역할

| 역할 | 범위 | 작업 지시 권한 |
|------|-------|-------------------------|
| 매니저 | 팀 | 생성, 배정, 상태 변경, 팀 구성원 관리, 팀의 모든 작업 지시 조회. |
| 기술자 | 팀 | 생성, 배정받은 작업 지시의 상태 업데이트, 완료 기록. 배정은 할 수 없습니다. |
| 요청자 | 팀 | 작업 지시 생성(제출). 제출 후에는 팀 작업 지시를 읽기 전용으로 조회합니다. |
| 조회자 | 팀 | 팀 작업 지시를 읽기 전용으로 조회합니다. 생성하거나 수정할 수 없습니다. |

## 작업 지시 생성 방법

### 1. 직접 생성
- **접근 위치**: 작업 지시 페이지(`/dashboard/work-orders`).
- **진입점**: "작업 지시 만들기" 버튼.
- **양식**: `WorkOrderForm` 모달. 제목, 설명, 설비(필수)와 함께
  선택 항목인 우선순위, 담당자, 팀, 마감일, 예상 소요 시간을
  입력합니다.
- **초기 상태**: 제출됨.

### 2. 특정 설비에서 생성
- **접근 위치**: 설비 상세 페이지(`/dashboard/equipment/:equipmentId`).
- **위치**: 작업 지시 탭.
- **동작**: 해당 설비가 미리 선택되고 고정된 상태로 양식이 열립니다.

### 3. QR 코드 스캔
- **접근 위치**: 휴대폰 기본 카메라로 설비 QR 코드를 스캔합니다.
- **흐름**:
  1. 사용자가 휴대폰 카메라로 QR 코드를 스캔합니다.
  2. URL이 `/qr/equipment/{id}`(또는 `/qr/inventory/{id}`,
     `/qr/work-order/{id}`) 형식으로 열립니다.
  3. `EquipmentQRScan`이 인증과 조직 컨텍스트를 확인한 뒤 대상 레코드로
     리디렉션합니다.
  4. 사용자는 해당 설비에서 바로 작업 지시를 생성할 수 있습니다.

## 작업 지시 배정

### 개인 배정
- 허용 역할: 소유자, 관리자, 팀 매니저.
- 담당자의 "내 작업 지시" 보기에 표시됩니다.
- 상태 업데이트에서는 개인 배정이 우선합니다.

### 팀 배정
- 허용 역할: 소유자, 관리자, 팀 매니저.
- 모든 팀 구성원이 작업 지시를 볼 수 있습니다.
- 매니저는 팀 안에서 다시 배정할 수 있습니다.

### 복합 배정
- 개인과 팀을 모두 지정할 수 있습니다. 상태 관련 작업에서는 여전히 개인 배정이
  우선하며, 팀 배정은 조회 범위를 넓혀 줍니다.

## 이미지 업로드

이미지 업로드는 [도움말 센터](https://eqrdocs.zinitek.com/support/technician-field-work/add-notes-and-photos)의
기술자 현장 작업 항목에 단계별로 설명되어 있습니다. 개발자를 위한
기술 규약은 다음과 같습니다.

- 이미지는 작업 지시 메모(또는 설비 메모)에 첨부됩니다.
- 지원 형식: JPG, PNG, GIF, WebP.
- 최대 크기: 파일당 10 MB.
- 메모당 최대 개수: 이미지 10개.
- 업로드된 파일은 Supabase Storage에 저장되며, 업로드한 사용자를 연결하는
  `equipment_note_images.uploaded_by`로 참조됩니다.
- 작업 지시에 업로드한 이미지는 설비의 이미지 탭에도 표시됩니다.

## 문제 해결

### 자주 발생하는 작업 지시 문제
1. **권한 없음** — 사용자의 조직 역할과 팀 소속을 확인하세요.
   팀 범위의 작업에는 그에 맞는 팀 역할이 필요합니다.
2. **설비를 찾을 수 없음** — 설비가 존재하는지, 사용자가 해당 설비의 팀에
   소속되어 있는지 확인하세요.
3. **배정 실패** — 담당자는 조직에 속해 있어야 하며,
   팀 배정의 경우 해당 팀에도 속해 있어야 합니다.
4. **상태 전환 오류** — 위의 전환 표를 확인하세요. UI에는
   유효한 다음 상태만 표시되지만, API를 직접 호출할 때도 같은 규칙을
   지켜야 합니다.

### 자주 발생하는 이미지 업로드 문제
- **이미지가 업로드되지 않음** — 파일 크기(< 10 MB), 형식(JPG, PNG, GIF,
  WebP), 네트워크를 확인하세요.
- **이미지가 갤러리에 표시되지 않음** — 작업 지시가 저장되었는지 확인하세요.
  설비의 이미지 탭은 작업 지시 메모와 설비 메모의 이미지를 모아 보여 주므로 업로드 후
  몇 초가 걸릴 수 있습니다.
- **이미지 품질이 낮음** — 조명이 충분한지, 렌즈가 깨끗한지 확인하고
  기기를 흔들리지 않게 잡으세요.

지원 페이지(`https://eqr.zinitek.com/support`, 문의 이메일과 응답 시간 안내.

`https://eqr.zinitek.com/dashboard/support`에서 문제를 신고할 수 있습니다.
