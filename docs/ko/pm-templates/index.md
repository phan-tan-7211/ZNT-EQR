## ZNTEQR 템플릿과 조직 템플릿

위 템플릿은 ZNTEQR에 **ZNTEQR 템플릿**으로 기본 제공됩니다. 예방정비 템플릿 페이지에서 설비에 지정하세요. 편집할 수 있는 조직용 사본이 필요할 때만 템플릿을 복제하세요.

## 여러 설비에 템플릿 일괄 적용하기

**운영 → 예방정비 템플릿**에서 모든 템플릿 카드에는 지정용 드롭다운이 있습니다. 일일 점검에서 사용하는 것과 동일한 다중 선택 도구입니다.

1. 현재 팀 범위에서 해당 템플릿을 사용하는 설비가 아직 없으면 버튼에 **장비에 지정**이 표시됩니다. 지정한 뒤에는 **지정된 장비 (개수)**가 표시되어 적용 범위를 한눈에 확인할 수 있습니다.
2. 목록에는 현재 조직의 설비가 표시되며, 상단 바에서 선택한 팀을 기준으로 범위가 정해집니다.
3. 검색한 다음 **모두 선택**, **모두 해제** 또는 **선택 반전**을 사용해 선택 항목을 구성하세요. 이미 해당 템플릿을 기본값으로 사용 중인 설비에는 **현재 기본 템플릿**이 표시됩니다.
4. **템플릿 지정**을 클릭하면 선택한 모든 레코드의 기본 PM으로 해당 템플릿이 설정됩니다.
