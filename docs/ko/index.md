## 앱 안에서 도움이 필요하신가요?

로그인한 사용자는 ZNTEQR 앱의 지원 페이지에서 **문제를 신고하고 티켓을 확인**할 수 있습니다.

**[eqr.zinitek.com/dashboard/support](https://eqr.zinitek.com/dashboard/support)**

로그인할 수 없나요? 공개 페이지 **[eqr.zinitek.com/support](https://eqr.zinitek.com/support)** 에 지원 이메일과 응답 시간이 안내되어 있습니다. ZNTEQR은 별도의 상태 페이지를 운영하지 않습니다.
